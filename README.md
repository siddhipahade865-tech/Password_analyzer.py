# Password Strength Analyzer

## About the Project

This is a simple Python-based cybersecurity project that checks the strength of a password. 
It analyzes the password using basic security rules and provides feedback to help
users create stronger and safer passwords.

## Features

* Checks password length
* Detects uppercase and lowercase letters
* Detects numbers and special characters
* Identifies common weak passwords
* Rates password strength (Very Weak, Weak, Moderate, Strong)
* Suggests ways to improve password security

## Technologies Used

* Python 3
* Regular Expressions (`re` module)
* File Handling
* Datetime module

## How to Run

1. Download or clone this repository.
2. Open the project folder in your terminal.
3. Run the following command:

   ```bash
   python password_analyzer.py
   ```

## Purpose

The goal of this project is to practice Python programming and understand the basics 
of password security and cybersecurity concepts.
